# Stay Fable Demo v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a repeatable WSL2 containerized backend and a WeChat DevTools simulator booking demo, merge it into `dev`, and tag the verified commit as `demo-v0.1.0`.

**Architecture:** A PowerShell entry point owns build, migration, seed, and Windows-to-WSL orchestration. A narrowly scoped Bash helper owns only labeled Docker resources in Ubuntu-22.04; the existing `/wx` develop runtime reaches the API through `127.0.0.1:3000` with mock identity and explicitly enabled mock payment.

**Tech Stack:** PowerShell 7, Bash, WSL2 Ubuntu-22.04, Docker Compose, Node.js 24, pnpm 11, NestJS, Prisma 7, PostgreSQL 17/PostGIS, Redis 7.4, native WeChat Mini Program, miniprogram-automator.
